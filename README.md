# Мәдениеттану: Великий путь

Два независимых фронтенда, синхронизированных в реальном времени без сервера Node.js —
через `BroadcastChannel` + `localStorage` (`shared-engine.js`). Подходит для одного
компьютера с несколькими вкладками/окнами (аудитория: один ноутбук/проектор + телефоны
студентов через локальную сеть и статик-сервер).

## Файлы

- `student.html` / `student.js` — экран участника: регистрация (имя + выбор региона,
  лимит 4/4), командное голосование, живая статистика своего региона. Никаких элементов
  управления игрой здесь нет.
- `teacher.html` / `teacher.js` — панель преподавателя: большая 3D-карта для проектора,
  таблица всех команд, запуск/пауза раундов, ручная корректировка баллов и экономики,
  конструктор вопросов, выгрузка ведомости в CSV.
- `shared-engine.js` — состояние игры, банк вопросов, правила, синхронизация.
- `scene3d.js` — 3D-сцена на Three.js с `OrbitControls`.
- `styles.css` — общая дизайн-система (dark sci-fi, glassmorphism).

## Запуск

ES-модули и `BroadcastChannel` между вкладками не работают при открытии файлов напрямую
(`file://`) в большинстве браузеров — нужен локальный HTTP-сервер:

```bash
cd culture-quest
python3 -m http.server 8080
# или: npx serve .
```

Затем откройте:
- `http://localhost:8080/teacher.html` — на компьютере преподавателя/проекторе.
- `http://localhost:8080/student.html` — на устройствах студентов (если сервер поднят
  с `--bind 0.0.0.0` или доступен по IP в локальной сети вуза, студенты заходят по
  `http://<IP-преподавателя>:8080/student.html`).

Открытые на одном компьютере вкладки `teacher.html` и несколько `student.html`
синхронизируются мгновенно через `BroadcastChannel`. Между разными устройствами в сети
синхронизация в этой версии не работает (`localStorage` не делится между машинами) —
для реального многопользовательского запуска по сети замените канал синхронизации в
`shared-engine.js` на WebSocket-клиент к серверу Node.js + Socket.io, сохранив тот же
интерфейс `GameEngine` (`onChange`, `_commit` → `socket.emit`).

## Правила игры

- 4 региона: Сарыарқа, Жетісу, Маңғыстау, Түркістан. Лимит — 4 участника на регион.
- Верный командный ответ: +25 культурного ресурса. Неверный: −20% экономики.
- Экономика ниже 30% — культурно-экономический кризис (визуально: туман, остров
  темнеет и "просаживается" на карте).
- Команда голосует за вариант совместно; засчитывается вариант с большинством голосов
  в момент отправки ответа капитаном команды или по истечении времени.
